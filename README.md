# Our Little Universe — For Bhawana ♡

A responsive romantic one-page website built with plain HTML, CSS, and JavaScript. No framework, database, or build command is needed.

## The proposal section

The proposal and letter reflect the real timeline: you have already met in person. The first button opens a message about missing the old relationship and wanting to try again. The second button displays a thank-you message that expresses your hope without taking away Bhawana’s choice.

## Add your five photos

Put these five files in the `assets/photos/` folder. Use these exact filenames:

1. `hero.jpg` — the main favorite photo for the opening section.
2. `memory-1.jpg` — a favorite selfie or memory.
3. `memory-2.jpg` — another selfie, screenshot, or special memory.
4. `first-meeting.jpg` — a place you dream of visiting together, or a photo for the first-meeting section.
5. `proposal.jpg` — a romantic photo for the proposal section.

JPG/JPEG is recommended. PNG or WEBP also works, but if you use another extension, update the matching filename in `script.js`. The `memory-1.jpg` and `memory-2.jpg` images are intentionally reused in other sections, so you do not need more than five photos. Until the images are added, the photo areas show `#` placeholders.

## Run it in VS Code

1. Extract the ZIP.
2. Open the `bhawana-website` folder in VS Code.
3. Put your five photos in `assets/photos/`.
4. Open `index.html` in a browser, or use the VS Code Live Server extension and click **Go Live**.

## Deploy to Vercel

Upload this folder to a GitHub repository and import that repository into Vercel, or upload the project using the Vercel dashboard. Select the folder containing `index.html` as the project root. No build command is needed.

## Note about privacy

Anyone who has the public website link can view the website and photos you publish on it. Only use photos you are comfortable sharing publicly. This static website has no login or private photo storage.
